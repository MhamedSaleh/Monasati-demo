🚀 التثبيت والبدء / Installation & Getting Started

الخطوة 1: استخراج الملفات

قم باستخراج ملف ZIP الذي حصلت عليه. ستجد الملفات التالية:

project/
├── HTML/
│ └── index.html
├── assets/
│ ├── css/style.css
│ └── js/script.js
├── documentation/
│ └── documentation.html (هذا الملف)
└── README.md

الخطوة 2: فتح الملفات

  1. افتح ملف index.html في محرر النصوص المفضل لديك
  2. يمكنك استخدام VS Code, Sublime Text, أو أي محرر آخر
  3. افتح index.html في المتصفح لمعاينة الموقع

الخطوة 3: تشغيل خادم محلي (اختياري)

لأفضل تجربة، استخدم خادم محلي:

# باستخدام Python
python -m http.server 8000

# باستخدام Node.js
npx http-server

# باستخدام PHP
php -S localhost:8000
نجح! الآن يمكنك الوصول للموقع على http://localhost:8000

🏗️ هيكل الملفات / File Structure

index.html

الملف الرئيسي للصفحة، يحتوي على:

  • شريط التنقل (Navbar)
  • قسم البطل (Hero Section)
  • قسم الشركات الموثوقة (Trusted By)
  • إحصائيات (Statistics)
  • المميزات (Features)
  • من نحن (How It Works)
  • فريق العمل (Our Team)
  • المدونة (Blog)
  • الأسعار (Pricing)
  • آراء العملاء (Testimonials)
  • الأسئلة الشائعة (FAQ)
  • دعوة للإجراء (CTA)
  • الفوتر (Footer)
  • النماذج المنبثقة (Modals)

style.css

ملف التنسيقات الرئيسي، منظم كالتالي:

  • CSS Variables: المتغيرات القابلة للتخصيص
  • Global Styles: الأنماط العامة
  • Component Styles: أنماط كل قسم
  • Responsive Design: Media Queries
  • Animations: الحركات والتأثيرات

script.js

ملف JavaScript يحتوي على:

  • تبديل اللغة (Language Toggle)
  • إدارة النماذج المنبثقة (Modal Management)
  • تبديل الأسعار (Pricing Toggle)
  • الأكورديون (Accordion)
  • التمرير السلس (Smooth Scrolling)
  • معالجة النماذج (Form Handling)

🎨 دليل التخصيص / Customization Guide

1. تغيير الألوان / Change Colors

افتح style.css وابحث عن :root في بداية الملف:

:root {
    /* الألوان الأساسية */
    --primary-color: #1D4ED8;  /* غيّر هذا */
    --primary-dark: #1e40af;
    --primary-light: #3b82f6;
    
    /* ألوان النصوص */
    --text-primary: #111827;
    --text-secondary: #6b7280;
    
    /* ألوان الخلفيات */
    --bg-white: #ffffff;
    --bg-light: #f9fafb;
    --bg-gray: #f3f4f6;
}
ملاحظة: عند تغيير اللون الأساسي، تأكد من تحديث جميع المتغيرات المرتبطة به.

2. تغيير الخطوط / Change Fonts

في ملف index.html، ابحث عن:

<link href="https://fonts.googleapis.com/css2?family=Cairo:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">

ثم في style.css:

body {
    font-family: 'Cairo', sans-serif;
}

3. تغيير النصوص / Change Texts

كل عنصر له نصين: عربي وإنجليزي

<h2 data-ar="النص بالعربية" data-en="English Text">
    النص بالعربية
</h2>

لتغيير النص:

  1. غيّر النص داخل data-ar للنص العربي
  2. غيّر النص داخل data-en للنص الإنجليزي
  3. غيّر النص داخل الوسم للقيمة الافتراضية

4. تغيير الصور / Change Images

ابحث عن وسوم <img> في HTML:

<img src="your-image-url.jpg" alt="وصف الصورة">

استبدل src برابط صورتك

5. إضافة قسم جديد / Add New Section

مثال على إضافة قسم جديد:

<section class="new-section">
    <div class="container">
        <div class="section-header text-center" data-aos="fade-up">
            <h2 class="section-title" 
                data-ar="عنوان القسم" 
                data-en="Section Title">
                عنوان القسم
            </h2>
        </div>
        <!-- محتوى القسم هنا -->
    </div>
</section>

ثم أضف التنسيقات في style.css:

.new-section {
    padding: 5rem 0;
    background: var(--bg-gray);
}

.new-section .container {
    max-width: 1200px;
    margin: 0 auto;
}

✨ شرح المميزات / Features Explained

1. تبديل اللغة / Language Toggle

الزر في شريط التنقل يبدل بين العربية والإنجليزية:

  • يغير اتجاه الصفحة (RTL ↔ LTR)
  • يبدل ملف Bootstrap (RTL ↔ LTR)
  • يحدّث جميع النصوص
// في script.js
function toggleLanguage() {
    isRTL = !isRTL;
    currentLang = isRTL ? 'ar' : 'en';
    // ... المزيد من الكود
}

2. تبديل الأسعار / Pricing Toggle

التبديل بين الأسعار الشهرية والسنوية:

  • يحسب السعر السنوي تلقائياً (شهري × 12 × 0.8)
  • يعرض شارة "وفّر 20%"
  • تأثيرات سلسة عند التبديل

3. النماذج المنبثقة / Modals

نموذج تسجيل الدخول/التسجيل

  • تبويبات سلسة بين تسجيل الدخول والتسجيل
  • إظهار/إخفاء كلمة المرور
  • تسجيل دخول اجتماعي (Google, Facebook)
  • التحقق من تطابق كلمات المرور

نموذج اتصل بنا

  • حقول كاملة (اسم، بريد، هاتف، موضوع، رسالة)
  • معلومات الاتصال في الأسفل
  • التحقق من الحقول المطلوبة

4. الأنيميشن / Animations

استخدام مكتبة AOS للأنيميشن عند التمرير:

<div data-aos="fade-up" data-aos-delay="100">
    المحتوى هنا
</div>
التأثير الوصف
fade-up يظهر من الأسفل للأعلى
fade-right يظهر من اليسار لليمين
zoom-in يظهر بتأثير التكبير
data-aos-delay تأخير بالميلي ثانية

الأسئلة الشائعة / FAQ
